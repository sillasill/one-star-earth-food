A one-star review of planet Earth written by an alien tourist who still admits the food was excellent. The program writes a single sentence (at most 200 characters) to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

This writes the review to `/output/entry.txt`. A different output path can be passed as the first argument: `python3 main.py /tmp/entry.txt`.
